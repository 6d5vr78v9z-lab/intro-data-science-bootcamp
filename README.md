# Intro a Data Science — Entregables

Notebooks resueltos del curso de introducción a Python para Data Science.

## Contenido

- **`pandas_titanic.ipynb`** — Resolución de los ejercicios del notebook
  `intro_to_pandas` + bonus de exploración del dataset del Titanic.
- **`intro_to_plotting_completed.ipynb`** — Resolución de los 9 ejercicios del
  notebook `intro_to_plotting` + bonus con el dataset de los taxis de Nueva York.
- **`kaggle_house_prices.ipynb`** *(en la rama `kaggle-challenge`)* — Reto de
  Kaggle "House Prices: Advanced Regression Techniques". Score público: **0.15451**
  (baseline de clase: 0.18878).

## Notas

- Los datasets (CSV, ZIP) **no se suben al repositorio**. El dataset del Titanic se
  carga desde una URL pública. Para el reto de Kaggle, los CSV deben descargarse
  desde la [página de la competición](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
  y colocarse en una carpeta `data/` en la raíz del proyecto.
